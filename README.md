# Amalino — open voices mirror

Copies of the open text-to-speech voices that [Amalino](https://amalino.app) (a free, non-commercial AAC app for children) offers for download. The app downloads from here first and checks every archive against a pinned SHA-256 hash; the original source is the [sherpa-onnx `tts-models` release](https://github.com/k2-fsa/sherpa-onnx/releases/tag/tts-models).
